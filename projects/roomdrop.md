# RoomDrop

**A local-first browser notes and capture extension.**

RoomDrop is built around a simple idea: save useful things from the web into your own local workspace without turning every capture into a cloud account, analytics event, or external upload.

## What it does

- creates and organizes notes into rooms
- saves selected webpage text
- saves page titles, URLs, and links
- supports quick capture through extension actions, shortcuts, and context menus
- provides note search, source links, and editing
- stores notes and settings locally in the browser
- supports user-triggered JSON backup/export

## Privacy model

RoomDrop is intentionally local-first. The current version does not require a RoomDrop account, does not use a RoomDrop cloud backend, and does not use third-party analytics or advertising services for note content.

The browser extension accesses webpage content only after an explicit user action rather than continuously monitoring browsing activity.

## Why I built it

RoomDrop is another example of the kind of software I like making: small enough to feel direct, but built around a clear opinion about how the product should behave. In this case that opinion is that quick capture should be useful without needing to give up ownership of the data being captured.
